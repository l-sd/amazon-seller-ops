## 必须纠偏或保留条件的地方

1. **CVR 分母不同**：教材 P0077 将 Orders/Clicks 与 Unit Session % 并列。广告归因订单/点击、订购件数/会话要分别标注；后者不是买家转化概率，不能直接相互替换。
2. **TACOS 与增量**：教材 P0090 的“看广告是否带动自然单”只能作为研究问题。比率变化还受时间归因、价格、促销、缺货等影响，不能证明因果；不把总销售额减广告归因销售额直接称自然销售。
3. **CPC 命名**：教材 P0267/P0480 的价格×转化率×可承受 ACOS 属条件估计。只有目标 ACOS 等于同口径广告前贡献率时，才称盈亏平衡 CPC；点击至订单与每单件数也要匹配。
4. **退款不能重复扣**：P0372 已写“净销售收入”又列退款/退货损失。先明确净收入是否已冲退款，已冲减金额不再扣；将货损、处理费和费用返还拆开，产品成本不再整单重复记账。
5. **库存不可混同**：P0367–P0368 明确在途、已接收不可售与可售不同。当前覆盖天数不直接把全部在途计入可售；按预计到达、接收和可售时间分批模拟。
6. **推断不等于行动有效**：教材阶段性广告/新品节奏是参考，不能固定按第几天就调价或承诺保自然位。主图、标题、优惠券、评价和认证的现行规则每次按适用类目/站点核验。
