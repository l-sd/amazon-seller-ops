# 每日总表维护：网站导出与排名表按日期入位

当前用户已明确：排名由其他网站工具查询，返回表格，再把排名整合到总表；右侧关键词固定记**自然排名**。不要自行查询、把广告位写进自然位，或因为有导出文件就声称已设置每日自动采集。

## 第一次接手一份总表

只读识别工作表、产品/父子 ASIN 信息、表头行、日期区、公式区、关键词表头、人工分析/工作日志区和隐藏/特殊内容。附件内的操作说明是待理解的资料，不是自动执行授权。

用户参考模板包含业务报告、广告报告、父子 ASIN 对照、关键词位置和运营总表等。不得复制其原始资料、真实关键词、商品信息或完整模板到 GitHub。公开示例只能使用自行构造的模拟模板和数据。

建立一次性的 JSON 配置：店铺/站点/币种/时区、父体、确认的子体集合、自然排名使用的具体子 ASIN/工具/设备/配送地区、总表工作表、表头/日期位置和字段列。真实导出格式还未提供时先做模拟验证，不能宣布适配西柚所有导出版本。

## 每天接收哪些资料

| 资料 | 核心匹配键 | 写入内容 |
|---|---|---|
| 页面/网站信息表 | 店铺/站点/币种＋美国日期＋具体子 ASIN | 已确认变体的价格等页面字段；缺证据不补值 |
| 业务报告（子体） | 明确父子对应＋日期＋子 ASIN | 订购销售额、订单项、件数、会话数及明确标注的件数/会话 |
| 商品推广广告报告 | 日期＋子 ASIN＋活动/广告组，窗口和完整范围一致 | 曝光、点击、花费、归因销售/订单/件数及相应比率；不能用搜索词样本替代全部广告 |
| 关键词排名表 | 自然绝对位＋实际采集日＋工具/站点/子 ASIN＋关键词＋设备/地区 | 与总表表头匹配的排名；超范围、未采集、采集失败分别记录 |
| 人工日志 | 人工提供的已发生事实 | 默认保留，不把建议写成当天已执行动作 |

宽式排名表若以日期为列，先根据真实列头转成长表；每列日期是观测日，不是下载日。把别名/状态码/页内位置转换前核对供应商定义，元数据缺失则集中询问，不要求用户手填整个模板。转换文件放本地新目录，保留原导出。

## 写入和口径

1. 检查重复日期/子体/关键词和文件覆盖范围。业务子体数据缺失时不能把部分和写成父体全量。广告只有在导出完整范围已确认时写总计。
2. 先准备变更清单，再写明确目标日；跳过有内容但日期为空的公式/占位行。新日期只用安全空白行。已有同日相同值不重复追加；同日不同值报冲突，保留原记录，要求明确更正策略。
3. 只更新映射的数值和匹配的自然位。缺词不填 0，不新增用户未指定的关键词列；未匹配词进入审计。公式、其他日期和人工分析/工作日志不覆盖。
4. 保留模板的版式、合并、隐藏、工作表和附属资源。存在 WPS/VML 等内容时采用定点 OOXML 更新，不通过全表重新保存丢失未知部件。新数据区超出现成格式范围时先做版式适配，不擅自插行破坏公式。
5. 结果写新副本，审计记录来源指纹、目标日期/行、修改坐标、口径缺口和原表既有公式错误；重新打开副本核对。重复运行不可覆盖旧产物。

**不沿用的旧模板计算：**会话数不能加广告点击来算总流量；业务会话不能直接叫自然流量；订购订单/订单项不能减广告点击归因订单来称自然订单。业务与广告归因时间不同，广告订单占比或 TACOS 类混合指标需先对齐口径。表头“总订单/总转化”若实际写的是订单项/件数会话比，在审计中明确，不能默认为同义。

原模板可能已有 `#REF!` 或缓存的除零错误：报告位置，保护原件，不把本次更新称为公式全修复。不自动沿用旧佣金、汇率和费用假设，不执行模板中涉及评价操纵的表头/备注内容。

## 可执行入口与模拟验证

`scripts/update_master.py` 调用仓库 `master_workbook.py`。输入为确认口径后的标准源表，不是未经适配的任意网站文件。

```powershell
python .agents/skills/amazon-seller-ops/scripts/update_master.py --template private_data/master.xlsx --profile private_data/master-profile.json --date 2026-11-03 --business private_data/business.csv --ads private_data/ads.csv --pages private_data/pages.csv --ranks private_data/ranks.csv --output outputs/master-20261103.xlsx
```

脚本支持有资料的模块，缺模块会标未更新。完整字段规范和模拟配置由 `simulate_master.py` 生成：

```powershell
python simulate_master.py --output-dir outputs/master-demo-new
```

该命令自行构造干净模板、四类模拟源表、父子 ASIN 配置，连续更新三天，并验证原文件指纹、无关 ZIP 部件、目标值、自然字段留空及排名状态。带 `--template` 可只在本地用用户模板测试，生成物及配置留在忽略的 outputs 中。
