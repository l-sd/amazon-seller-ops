# 哪些日常任务适合 Skill

按用户提供的材料选择，不默认检查全店，也不把清单当作每家公司统一 SOP。

| 任务 | 输入 → 交付 | 频率参考与自动化边界 |
|---|---|---|
| ASIN 反查与词库维护 | 多 ASIN 反查 → 去重、相关性、意图、优先级与排除依据 | 首次建库/阶段性扩词；不是每天重新替换整套词 |
| 关键词排名日报 | 监控导出＋历史 → 自然/广告分开的日序列、变化和待核查词 | 每日有新采集后更新；已有本地脚本，不含自动抓取或调度 |
| 竞品关键词缺口 | 同窗口反查或排名 → 竞有我未观察到、共同词差距、验证优先级 | 周期性/新品阶段；没有覆盖证据不下“未收录”定论 |
| 搜索词复盘 | SP 归因完整的报表＋目标 → 迁词/否定/预算复核草稿 | 日常看异常，定期深入；复用报表脚本，不自动执行 |
| 页面词覆盖与事实核查 | 已核实产品资料＋词库＋页面 → 覆盖矩阵和文案任务 | 新品/页面修改前后；文本出现不证明被索引，更不证明带来排名 |
| 竞品价格/页面观察 | 同地区具体变体快照 → 价格/优惠条件/内容变化 | 每日或重点事件；快照脚本可比较，但不证明降价原因 |
| 销售日报与异常 | 同口径按日销售表 → 日报、变化与缺口 | 每日完整日数据；复用已有脚本 |
| 库存与入仓跟踪 | SKU 销量、可售、分批 ETA、交期 → 覆盖与延误/补货评审 | 日常异常/周期复盘；目前是分析流程，未实现专用库存引擎 |
| 评论/退货问题归类 | 获准使用的反馈、VOC、退货原因 → 问题主题和页面/产品待办 | 按业务量；样本占比不是全店故障率，回复仅草稿 |
| 周报与行动复查 | 日报＋排名/广告＋实际改动日志 → 哪些异常持续、哪些动作已执行、下周重点 | 周期性；观察性变化不能作因果业绩 |

本次实务检索的重点是反查词库、监控词和观察排名的闭环。工具教程中的固定名次线、笼统“词频代表权重”、推测算法阶段，以及任何操纵销量/评价的建议均不采纳。选择工作流和材料，不复制营销结论。
