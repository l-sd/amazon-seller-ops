## 工作流人工审阅

以下为编写者的静态检查，不是独立代理盲测或真实业务验收：

| 场景 | 对应处理 |
|---|---|
| 只有销售报表，却要求“店铺全面巡检” | 产出销售部分，其余账户/库存/售后标未检查，不写正常 |
| 只有公开商品链接，没有付费数据 | 完成可访问字段对比，销量/搜索量/市场份额标未知 |
| 想选品但没有采购价和费用 | 输出需求/竞争证据与成本缺口，不给确定利润率或采购结论 |
| 竞品快照少了一条记录 | 标未复查到，不判下架；新增记录也不判新品上市 |
| 用户要求分析广告，未要求修改 | 提供复核候选和具体建议，不执行否定词或调价 |
